# 给朋友的试用介绍

我做了一个叫「页间」的读书摘录小工具，想请你试试：读到想留的句子，可以填上书名和摘录，保存后在列表里回看，新记录排在前面，多行文字也会保留换行。打开我发你的 `reading-notes/index.html` 就能用，不用安装或登录，断网也可以。目前只支持新增和查看，没有搜索、标签、编辑、删除、导入导出或云同步。笔记只存在当前浏览器里，清除浏览器数据会丢失，换浏览器、设备或移动文件也不保证能找回；请先用几条测试摘录，并固定用同一浏览器打开同一个文件，避开隐私窗口。真实浏览器里刷新后能否保留，还需要这次试用确认。想请你试着保存两条摘录、刷新，再从列表找回其中一条，告诉我：内容是否还在、哪一步让你犹豫或遇到报错、找回是否方便，以及和你平时的记录方式相比有什么差别、什么情况下会用它。遇到问题请带上浏览器、设备和操作步骤，方便我复现。

## 写作依据（不必转发）

- [当前范围与实现](../COLLABORATION_PLAN.md)：本版只做书名、摘录的新增和列表回看；没有恢复搜索、标签、备份等能力。
- [使用说明](../README.md)与[页面代码](../reading-notes/index.html)：浏览器直接打开，无外部资源；使用 localStorage 保存，新记录在前，正文保留换行。两字段必填，书名最多 200 字符、摘录最多 20,000 字符；每批显示 20 条，可点击显示更多。正文保留影响试用的主要边界，详细操作与存储失败时的本地服务入口见 README。
- [技术验证](prototype-verification.md)与[边界检查](edge-case-check-report.md)：模拟页面环境中的保存、重载、必填、多行与文字显示检查通过；Chrome 启动失败，真实浏览器刷新持久化尚未验证，不能把模拟重载写成实际浏览器通过。
- [已有试用材料](reading-notes-10min-trial.md)：关注能否记录、能否找回、与原有记录方式的差别；材料已准备，尚无朋友试用结果。

## 仍缺的证据

- 朋友在实际浏览器中能否打开、保存、刷新后看到完整内容，以及是否出现布局或操作问题。
- 未经讲解能否理解保存结果、从列表找回目标摘录；小列表的体验不能代表大量笔记。
- 是否适合朋友真实的读书习惯。试用完成或口头表示愿意用，不能证明会长期使用；本文未声称节省时间或提升效率。

正文仅描述当前能力、限制与本次希望获得的反馈，没有加入未来功能或功能承诺。
