# 页间 · 读书笔记原型

## 怎么打开

1. 在当前项目中找到 `reading-notes/index.html`。
2. 双击它，用 Chrome、Edge、Firefox 或 Safari 打开；也可以把文件拖入浏览器窗口。
3. 填写书名和摘录，点击「保存笔记」。笔记立即出现在列表中，新记录在前，正文保留换行。
4. 刷新页面，确认笔记仍在。后续使用同一浏览器打开同一个文件。

不需要安装依赖、启动服务或登录。文件没有外部字体、脚本和网络请求，断网也能使用。

## 保存位置与边界

笔记保存在当前浏览器的本地存储（localStorage），不是写入项目文件或独立文本文件。换浏览器、换设备或移动页面文件，不保证能看到原笔记；清除浏览器数据会删除笔记，隐私窗口数据通常在关闭后消失。不要用隐私窗口保存需要长期保留的内容。

部分浏览器或隐私设置可能限制直接打开文件时的本地存储。页面会显示读写错误，保存失败时保留输入。若遇到这种情况，可在项目目录运行 `python3 -m http.server 8000`，然后打开 `http://localhost:8000/reading-notes/`；以后固定使用这个地址。文件入口和本地服务入口的数据互不共享。

本版仅提供新增和列表。书名与摘录均必填；书名最多 200 字符，摘录最多 20,000 字符。列表每次显示 20 条，可继续点击「显示更多笔记」。不含登录、标签、搜索、编辑、删除、导入导出或云同步。

## 快速验收

- 首次打开应看到空列表。
- 尝试空白保存，应显示字段提示，并聚焦需要填写的字段。
- 保存两条中文笔记，其中一条有多行摘录；检查完整内容、换行及新记录在前。
- 刷新同一页面，应仍看到两条笔记。
- 缩窄浏览器窗口，应能正常填写、保存和阅读。
