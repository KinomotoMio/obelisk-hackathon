# 校园失物招领｜从辨认物品到找到核实路径

探索阶段交互设计 · HTML v0.2 · 整理日期：2026-10-08  
**当前状态：已有原型与试用材料，尚未进行真实试用，未上线。**

## 问题：看到相似物品后，怎样判断和继续？

我把这轮设计聚焦在一个具体情境：同学在失物信息中看到一件相似物品，需要判断是否值得进一步核实，再找到下一步的联系办法。已有项目说明提出“照片不好认”“联系方式乱放”两条线索，但它们与前期访谈、页面的对应依据仍待补齐。现在还不能确定这些问题出现的频率，也不能把反复比对、寻找入口的负担写成已观察到的事实。

这轮希望改变的是：让使用者能结合外观、时间、地点和特征判断相关性，并知道向谁进一步核实。是否确实减少犹豫和绕路，需要通过实际操作观察确认。

## 我的选择：先做清楚一条关键路径

| 选择与已做内容 | 为什么这样尝试／保留的边界 |
| --- | --- |
| 用“列表 → 详情 → 线下联系说明”组织路径，暂不扩展搜索和发布 | 先集中检查辨认与联系两个环节；这不是完整失物招领产品。 |
| 列表提供物品图、发现时间、地点和简短特征；详情补充完整插画与特征描述 | 尝试用多种线索支持判断，不先认定放大照片就能解决问题。当前使用示例插画，真实照片质量尚无法验证。 |
| 按本轮决定，不要求填写手机号，详情统一提供“线下联系失物招领处”入口 | 把联系对象和渠道说清楚。旧原型本就没有手机号表单，本轮实际新增的是入口与说明；不能据此宣称隐私或联系效果已经改善。 |
| 明示发现地点与实际到访信息的区别，保留“地点、开放时间、核验要求待补” | 不把发现地点当领取地点，也不暗示物品已经移交。当前说明还不足以安排真实到访。 |

## 接下来验证：先观察操作，再解释原因

试用前，先准备独立目标参考图、补充相似物品并完成关键路径走查；找回匿名访谈记录，确认两条问题线索的来源。邀请有失物或拾物经历的同学，尽量加入未参加前期访谈的人，用虚构任务观察：

1. **能否辨认相关物品？** 记录首次选择、最终判断、误认或不确定，以及实际使用了哪些线索；正确定位与确认归属分开。
2. **能否找到并理解联系路径？** 记录绕路、求助、停止位置；找到入口与理解“线下联系失物招领处”分别判断。
3. **下一步还缺什么？** 先听参与者如何理解说明，再追问缺失信息。实际地点、时间、核验及保管／移交方式需向负责人确认，真实到访另行验证。
