# 联系方式口径变更｜差异与核对清单

日期：2026-10-08。权威来源：用户本轮明确要求“取消填写手机号，改成线下联系失物招领处”。适用范围：当前校园失物招领原型及其说明、任务卡、观察表和关联准备计划。属于当前版本决定，不代表线下方式已验证有效，也不抹除历史研究线索。

## 新旧要求

旧试用材料要求模拟填写联系方式、选择渠道与公开范围，使用“测试账号 A”；旧 HTML v0.1 实际并没有手机号或其他联系方式表单，也没有联系入口。新标准要求当前版本不填写手机号、通过说明引导线下联系失物招领处。本次没有删除已有表单，而是移除旧测试要求，并新增线下入口与说明。

用户尚未提供失物招领处地址、开放时间、核验材料要求，也未确认物品移交／保管流程。不能将发现地点当成领取地点，不能声称示例物品已交给失物招领处。
