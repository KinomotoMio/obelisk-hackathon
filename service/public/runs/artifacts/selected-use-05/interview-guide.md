# 校园失物招领｜十分钟试用访谈

状态：材料已准备，原型试用待执行，尚无试用结果。已有页面草图及 3 位同学的前期访谈，访谈依据仍需整理；前期访谈不等于原型试用。配套[观察记录表](campus-lost-found-test-record.md)。

## 本轮问题与准备

| 自己猜的（未验证） | 要留下的证据 |
| --- | --- |
| 图文线索能帮助辨认物品 | 实际选择、判断依据、误认或不确定 |
| 联系入口容易找到并理解 | 首次操作、求助、对渠道的理解 |
| 同学愿在一定条件下留联系方式 | 模拟自主选择及真实情况下的口头意愿，分别记录 |

每人最多十分钟，尽量加入未参加前期访谈的同学。开始前记好版本，准备列表、详情、联系入口和联系方式设置页；不可操作处注明，纸面模拟由同学指点、主持人按预定路径换页。本轮不做 A/B。

准备一张任务卡，含目标参考照片、遗失时间、地点与特征；列表放目标和 2–3 件相似物品。提前写好目标条目与匹配线索，不临场改答案。发布页其他字段预填模拟资料，联系方式用“测试账号 A”，不使用真实账号、不发送或真的发布。设置页未完成时仅问口头选择，标为操作未测。

## 0:00–1:00 开场与经历

照读：“想请你花十分钟试一下失物招领原型。测的是原型，你可以跳过或随时停止，不用照顾我的感受。只用模拟联系方式，不会真的发布。可以记匿名笔记吗？记录用于项目研究，作品集只用匿名内容。”不同意记录则不开始；录音、录屏另征同意。

问：“最近一次丢东西或捡到东西，你当时怎么处理的？”没有经历就注明，不要求编造。

## 1:00–4:00 T1 辨认物品

给参考照片和任务卡：“假设你丢了这件物品，请用原型找找有没有可能是你的，并决定下一步。判断不出来也可以说不确定。”

先观察，不指出目标。结束后问：“你根据什么这样判断？可以指出具体信息吗？”“还有什么不能确认？”

记首次选择、最终判断、线索和卡点。定位目标与确认归属分开，不以信心代替结果。

## 4:00–6:00 T2 联系入口

“假设你想向这条信息的发布者核实一个细节，请从当前页面继续，停在真正发送之前。”T1 未找到目标时，主持人打开预设详情页，记下换页；T2 从此开始。

先观察，再问：“你预计这一步之后会发生什么？谁会看到哪些信息？”分别记找到入口、理解渠道及主动停止。公开机制没说明就记“无法判断”，不替原型补充保证。

## 6:00–9:00 T3 联系方式选择

打开预填的发布页：“假设你捡到这件物品，其他资料已填好。请按自己的想法决定是否留联系方式、留什么、让谁看到；需要填写时用测试账号 A。到提交前停下。”

先观察填写、跳过、改渠道、查看说明或退出，再问：“为什么这样选？你理解谁能看到、什么时候看到？”“换成真实联系方式，你会怎么选？什么条件下会改变？”

强制填写时记下要求，再问“如果可以跳过，你会怎么选？”回答只算口头意愿。模拟填写不代表真实留联，本轮不实际提交、不测试完整发布流程。

## 9:00–10:00 收尾

“刚才哪一步最难决定？缺了什么信息？”记下并感谢参与，十分钟到时结束。

## 主持人速记规则

- 先操作后追问，不讲设计意图、不纠正、不问“是不是很好用”。只针对实际停顿问“你刚才在想什么？”
- 求助先问“你原本打算怎么做？”仍卡住可给最少提示，记提示内容，标“经帮助”。到本段时间上限即结束，未完成、未测如实留存。
- 行为、原话、解释分栏；未逐字记录标“转述”，空白不是成功。
- 第二组证据不足辨认和完整发布流程留待后续。不能据本轮推断这些流程有效、真实联系率或认领成功率。
