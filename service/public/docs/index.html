02 / CONTEXT

知识付费，从描述走向证据

找回真实发生过的事

Obelisk 在本地索引 AI 编程会话，让 Agent 按需检索消息、工具调用与结果，回答能够追溯到原始上下文。

把经验变成可复用的 Skill

从历史中沉淀方法，留下出处、作者、版本和内容指纹。衍生关系形成族谱，让最初的分享者继续获得认可。

用真实使用帮助选择

买家关注内容价值、价格与使用表现。顺利率统计顺利、返工和失败；无法判断的结果不进入分母，样本量同时展示。

让分享的人一起受益

创作者选择免费或定价发布。购买与分成连接作者、上游贡献者和平台；创作者在自己的 App 中查看收入，平台从运营视角核对分配。

分享你的知识，让更多人从中受益，也让你和最初愿意分享的人得到回报。

04 / FIRST STEPS

从一句日常请求开始

  1. 让 Agent 完成本地安装，按提示进入隔离环境并建立会话索引。
  2. 在这个环境启动 Agent，试着说：“帮我看看这个项目最近在忙什么，有没有值得保留下来的方法？”
  3. 审阅它找到的会话与 Skill 草稿。确认内容和分享范围后，再决定是否铸造、发布或分享。
已有本地代码？手动进入环境
sh scripts/hackathon-env.sh
source ~/.obelisk-hackathon/env.sh a testnet
obelisk --build

角色 A / B 有独立的数据目录、Skill 库和钱包。CLI 与从该终端启动的 App 使用相同环境；已运行的 App 需要重新启动。
