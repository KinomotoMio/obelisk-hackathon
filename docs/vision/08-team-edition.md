# 08 · 团队版愿景

> 把团队的 AI 工作经验，变成可流转、可计量、可治理的资产。团队版是阶段 3 的方向，黑客松路演中作为愿景提及。

## 为什么团队需要

个人版解决的是"我的经验怎么安全地给别人、怎么证明价值"。团队里同样的问题被放大：经验散落在每个成员的电脑上；新人接手要从头摸索；外包和离职让访问权限难以收回；团队采购外部 Skill 时，不知道钱花得值不值。

## 团队场景

| 方向 | 场景 | 说明 |
| --- | --- | --- |
| 沉淀与复用 | 团队技能库 | 成员沉淀的 Skill 在团队内免费使用；对外售卖的收入按贡献分成 |
| 沉淀与复用 | 新人入职 | 把老员工相关的 session 打包成上下文包，分享给新人的 AI 助手直接使用 |
| 分享与权限 | 外包与跨团队协作 | 给对方限时、限次、带水印的访问，项目结束自动失效 |
| 分享与权限 | 离职交接 | Skill 和 session 的归属转交；成员离开团队后访问自动失效 |
| 分享与权限 | 敏感项目分级 | 分享前的隐私体检按团队规则执行，例如禁止外传客户名称 |
| 度量与激励 | 团队使用面板 | 哪些 Skill 被谁、在哪些项目里使用，效果如何 |
| 度量与激励 | 贡献激励 | 内部 Skill 的真实调用次数计入贡献度 |
| 治理与采购 | 审计留痕 | 谁在什么时候看过哪些 session，链上可查，配合泄露追踪 |
| 治理与采购 | 企业采购 | 为员工批量采购外部 Skill 和上下文授权，按真实调用量付费 |

## 与个人版的关系

团队版不需要新的底层能力，复用的都是个人版已经具备的东西：钱包身份、限次限时的授权、已读回执、水印与泄露追踪、真实调用量、按用量分成。新增的是团队这一层：成员资格、团队规则和团队级面板。
