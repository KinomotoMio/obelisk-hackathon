# Skill 市场结算进度（#42）

当前仅完成合约与本地验证，尚未部署，服务和界面接入后才验收 #42。

## 本轮规则

- 作者选择免费、按次取用、固定版本买断，以及个人或商用许可。按次是一次授权取用正文，不声称能限制已下载文本在本机的调用次数。
- 作者首次上架时设置后续衍生作品应留给自己的上游比例；比例固定，避免后来的修改改变已有衍生者的义务。父作品先设置规则，衍生作品再上架，最多 16 层。
- 先分平台费用，再沿族谱递归分配：每层留下属于自己的金额，将父作者约定的比例传给父层。所有舍入余数归当前层，金额总和等于付款。
- 平台钱包和费率在部署时明确配置；本地验证使用 5%，作者要求的上游份额使用 20%，均为 Demo 配置，不是正式运营费率。
- 上架产生不可变 offer，签名绑定 offer id，因此绑定价格、版本和许可。更新上架后拒绝购买旧 offer；已购买权益保留。同版本同许可买断后不会因改价再次收费。
- 买家签名不能单独转移其资金：交易发送者提供购买本金。生产购买须由买家实际出资；测试网角色演示可以明确用演示资金支付，不能把代付 gas 说成代付购买本金。
- 所有收款在同笔交易完成；任何收款失败则整笔回滚。收据、收入索引与分配明细提供链上读取接口，不依赖日志查询。

## 接入边界

服务需要用链上权益保护新增付费正文并实现可恢复的取用交付。旧公开正文保持公开；上架不能让已经公开的内容重新成为秘密。按次取用必须处理确认交易后交付失败时的重试，不能重复扣额度。

买家界面展示内容价值、价格、许可、购买状态和衍生邀请；创作者 App 展示本人资产、规则与收入；平台视角展示经营收益。具体分账义务在衍生上架确认时显示。

## 已验证

`chain/test/SkillMarket.test.ts` 在本地 EVM 验证真实余额变化：三代作者及平台共收到 10,000 单位，分别为 7,600 / 1,520 / 380 / 500。另验证重复签名、金额错误、无取用额度、重复买断被拒，免费许可、旧购买权益继续有效。

这不是 BOT 测试网交易证据，也不是付费正文已经交付的证据。后续需补测试网交易、各角色界面及取用闭环。
