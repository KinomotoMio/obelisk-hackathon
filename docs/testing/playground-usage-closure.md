# Playground 使用闭环（2026-10-08）

用户要求优先补实际使用、钱包数、smooth 和主网内容。本轮保留前几批未自动选用、工具读取漏计的原始记录；新增的是模拟用户主动选用已知市场方法，再用自然请求完成日常工作。不是自主发现样本，也不是固定输出的诊断。不同角色各有独立钱包与原生 Codex session。

## 执行方式

场景文件 `selected-skill-use-04`、`selected-use-05-*`、`selected-use-06-builder`、`selected-paid-use-07` 使用 `$技能名` 表示用户在产品中选中的方法。其后的请求是项目排期、招聘消息、交接、试用准备等日常任务，不包含计量 SOP 或指定结果。Codex 原生加载正文，指纹与已发布版本对应；本机 Codex judge 阅读真实任务片段，再通过 UsageStats 上报。

交互会话仍默认静置 30 分钟。新增 `usage judge --completed-run <provenance.json>`，对 Playground 已成功结束且非 dry-run 的 session 提前判定；如果索引里的最后消息晚于该步骤结束时间，仍等待普通静置窗口。不会修改历史时间，也不会预设 smooth。完成记录是本地操作者输入，不是链上对执行真实性的证明。信号统计仍按原静置窗口生成，结果判定可以先上报。

必要验证：CLI 编译通过；usage judge 相关 4 个测试通过，包含已结束任务立即判定和继续发言后不能复用旧完成记录。实际两网执行、判断和交易另见本次结果文件。

## 已有证据与本轮数据的关系

- 第一批保留自然搜索、候选不适合和没有取用的情况。
- 第二批保留安装路径问题和工具读取未计入原生加载的结果。
- 本轮是明确选择后的真实使用，不能替换前两批，也不声称模拟钱包是真实客户规模。
- smooth 表示这次请求在可见会话里完成且未见返工；例如“准备访谈提纲”完成，不代表真实访谈已经执行。
- 已购买的测试网 #14 在原购买/授权基础上使用；购买与分账交易见 `market-settlement-testnet.md`。

## 主网内容

独立主网服务已有 #1 原始协作方法、#2 半小时验收方法、#3 小项目证据循环、#4 范围变更交接。族谱为 #1 → #2 → #4；由三个独立作者钱包发布。内容来自已存在的真实 AI 草稿，主网发布不冒称新增创作。

主网使用由新隔离角色 `mainnet-builder`、`mainnet-designer` 执行，测试网调用不会搬成主网计数。主网总支出继续不超过先前执行上限 0.25 BOT。

公开入口：测试网 `/market/skills/10`、主网 `/market/skills/1`，以及两网 `/runs`。本轮公开产物在 `/runs/artifacts/selected-use-05/`：招聘消息、周末交接、访谈提纲和观察表。原始文件保留在各角色 workspace。
